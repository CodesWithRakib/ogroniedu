# 01 — Product Vision

**Vision:** Make reliable, accountable tutoring easier to discover, arrange, deliver, and evaluate for Bangladeshi learners and families.

## Learner coverage

Class 1–5, 6–8, 9–10, 11–12, SSC/HSC, relevant boards/curricula, science/humanities/business studies, university admission preparation, university-level tutoring where appropriate, language and skills categories where validated. Represent classes, curricula, streams and subjects as managed reference data, not hardcoded UI conditions.

## User groups

Guest; guardian with multiple children; independent learner; minor learner linked to guardian; tutor; optional coaching-centre owner/staff; support staff; admin; super admin. A role is not proof of resource ownership.

## Tutoring modes

In-person/home, online, hybrid, one-to-one, group, trial, recurring sessions. Keep MVP scope small while documenting long-term capabilities.

## Principles

Safety before growth; explicit consent; transparent fees; data minimization; fair discovery; accessible Bangla/English; human review for high-impact disputes; no fabricated reviews or outcomes; user-owned learning records exportable.

## Pilot measures

Active verified tutors, time to suitable match, request-to-booking conversion, completed lessons, repeat bookings, no-show/cancellation rate, payment reconciliation, dispute resolution time and willingness to pay. Establish baseline before setting numerical targets.
