# 15 — Learning Management

Core records: assignments/homework, submissions, assessments, results/feedback, lesson notes, progress reports, attendance and resource attachments. Every record has author, learner scope, timestamps, status and visibility policy.

Tutors can create records only for learners connected to an authorized booking/relationship. Guardians see only linked children's permitted records. Reports separate observable activity (attendance, homework, assessment results) from subjective feedback; do not claim mastery without evidence. Changes to results/reports should preserve audit history.

Tests: unrelated learner access denied; tutor cannot edit unrelated student; learner cannot alter tutor grade; revisions audited; private resources inaccessible publicly; export/deletion follows retention policy.
