# 30 — Glossary

- Guardian: authorized adult managing learner account(s).
- Independent learner: person managing own account subject to policy.
- Verification: documented checks; not a guarantee.
- Booking: agreed tutoring service arrangement.
- Session: scheduled lesson under a booking.
- Outbox: event intent persisted in same transaction, published asynchronously.
- Idempotency: retries do not create additional effects.
- Ledger journal: financial event represented by debit/credit entries.
- RPO: maximum acceptable data-loss window.
- RTO: target restore time.
- RBAC: role-based access control.
- BOLA: broken object-level authorization.
- SLO: service-level objective.
- Traceability: mapping requirement to design, implementation, tests and evidence.
