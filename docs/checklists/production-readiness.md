# Production Readiness Checklist

- [ ] Policies/legal review and provider approvals complete
- [ ] Tutor verification and support/dispute processes staffed
- [ ] Guardian/minor consent reviewed by qualified counsel
- [ ] BOLA/role tests pass; private files protected; admin audited
- [ ] Export/deletion/retention documented
- [ ] Webhook signature/replay tests pass; refunds and reconciliation tested
- [ ] Ledger balances if enabled; finance review complete
- [ ] Backups configured and restore drill passed
- [ ] Monitoring, alerts, runbooks and rollback tested
- [ ] Performance baseline and capacity assumptions documented
- [ ] CI gates enforced; migration upgrade path tested
- [ ] Accessibility/localization checked; no critical defects
- [ ] Documentation matches deployed behavior
