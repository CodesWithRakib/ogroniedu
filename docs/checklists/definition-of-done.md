# Definition of Done

- [ ] Requirements and acceptance criteria linked.
- [ ] Module boundaries and ownership rules respected.
- [ ] Server validation and authorization implemented.
- [ ] Migrations and constraints reviewed.
- [ ] Unit/integration/E2E tests cover appropriate paths.
- [ ] Negative authorization and failure cases tested.
- [ ] Bangla/English complete; responsive and keyboard behavior checked.
- [ ] Loading/empty/error/success/permission states handled.
- [ ] Logs/audit safe and useful.
- [ ] No secrets or production mock data.
- [ ] Lint/typecheck/tests/build actually pass.
- [ ] Docs and traceability updated.
- [ ] Risks/blockers reported honestly.
