# 28 — Feature Roadmap

0 Discovery: interviews, competitor review, legal/provider validation, pilot economics.
1 Foundation: audit, ADRs, monorepo, CI, config, localization, DB migrations, observability.
2 Identity/trust: auth, sessions, RBAC, guardian links, tutor onboarding/verification.
3 Discovery: reference catalogs, public profiles, filters, areas, requests.
4 Booking: state machine, schedule conflict protection, cancellation, reminders, attendance.
5 Learning: homework, submissions, assessment, reports, guardian view/export.
6 Financial: sandbox provider, verified webhook, idempotency, receipts, refunds, ledger/reconciliation.
7 Operations: support, disputes, replacement, admin, notifications, analytics.
8 Hardening: security, accessibility, localization, load, restore drill, CI, runbooks.
9 Local pilot: small cohort, manual operations monitoring, weekly metric review.
10 Expansion: additional localities, coaching SaaS, advanced matching and other validated features.

Every phase requires actual test results, docs, no unresolved critical defects, and a recorded go/no-go decision.
